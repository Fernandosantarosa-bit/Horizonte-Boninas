# Horizonte Boninas — Transporte Personalizado

Aplicativo de transporte personalizado da Horizonte Boninas para viagens e deslocações entre Luanda, Sumbe e Benguela.

## Stack
- React + TypeScript + Vite
- Supabase
- Interface responsiva/PWA

- Administração/Despacho
- Viagens interprovinciais

- Avaliações e suporte
